# 我的工作日 · my_workday

Home Assistant 自定义集成：判断今天是不是工作日（**包含国务院的调休与补班**），并给出本月剩余工作日天数。

> Home Assistant custom integration for Chinese workdays — handles the official holiday swap
> (make-up workdays on weekends), which the built-in `workday` integration cannot do.

---

## 为什么需要它

HA 自带的 `workday` 集成用 `holidays` 库，只认法定节日，**不认"周末补班"**。所以国庆前后那种"周六要上班"的日子它判不出来，用它做的自动化在调休周会全部错乱。

本集成直接读 [holiday-cn](https://github.com/NateScarlet/holiday-cn) 的年度日历——国务院办公厅一公布，那边就更新，补班日也在内。

## 功能

- **今天是否工作日**：`on` / `off`
- **本月剩余工作日（含今天）**、**本月工作日总数**，单位「天」
- 每天 0 点自动翻页，不需要重启，也不需要任何模板
- 可以自己指定某天"算上班 / 算休息"（财务月结、公司单独调休），**优先级高于国家安排**
- 自定义日期、待办、纪念日都存在 HA 本地 `.storage`，重启不丢，超过 500 天的自动清理
- 日历上**右键或长按格子**弹菜单，可快捷新增**待办**（能勾完成）和**纪念日**（每年重复 / 一次性）
- 待办按**逾期 / 今天 / 未来 7 天 / 以后 / 已完成**分组，日历格子里直接显示当天要做什么

## 安装

### 方式一：HACS（推荐）

1. HACS → 右上角「⋮」→ **自定义存储库**
2. 仓库地址填 `https://github.com/ACEweijun/my_workday`，类型选 **集成** → 添加
3. 在 HACS 里搜索「我的工作日」→ 下载
4. **重启** Home Assistant
5. 设置 → 设备与服务 → **添加集成** → 搜索「我的工作日」→ 提交

### 方式二：手动

下载本仓库，把 `custom_components/my_workday` 整个文件夹复制到 `/config/custom_components/` 下，重启 HA，然后按上面第 5 步添加集成。

## 自带的日历界面

集成装好、重启之后，**侧边栏会多一个「我的工作日」**，点开就是日历（手机上跟原生页面一样）。

**顶部概览** — 一整条卡片分成三段（竖线分隔），不用三个方块拼：

- 左段 `12/21` + 「本月工作日 · 剩余/总数」（数字蓝色；**翻到别的月份时自动变成该月总数 + 「12 月工作日总数 · 2026 年」**，不会再顶着「本月」误导人）
- 中段「上班 / 休息」，小字是「今天 · 2026年11月13日」，点一下回到本月
- 右段 `49 天` + 「距离元旦 · 还需上 35 个工作日」（数字橙色，「天」是小字）

三段内容都是**居中**排布的。

**月历** — 周一到周日，固定 6 行，前后月的日期淡化补位。**格子大小固定**（不会被长文字撑开），蓝底=工作日，灰底=休息，节日名字直接标在格子上，补班日标「补班」。顶部有年份、月份两个下拉和左右翻页，也能点浅色日期直接跳到那个月。格子右上角的小字表示那天有什么：**「待」=有待办**，**「纪」=有纪念日**（格子右上角已有「班 / 休」角标时，标会自动挪到角标下面）；**当天有未完成待办时，格子底部显示第一条待办的文字**（太长自动省略号截断，不会换行把格子撑变形），**当天有多条待办时，右下角挂一个红色圆角数字角标**（如 `3`），一眼看出这天有几件事。鼠标悬停格子可看当天全部待办。
**点格子改** — 第一次点只**选中**该格（橙色虚线框），之后每次点都在「与原本相反的状态」之间切换：天然上班的改成休息、天然休息的改成上班，再点一次恢复原状。跟原本状态相同的标记不会重复打（天然休息的格子不会再标「休」）。

**右键 / 长按格子** — 先选中该格（虚线框跟随），再弹出菜单。菜单**宽度固定**，内容跟着这天的实际情况变：

- **当天的待办和纪念日直接列在菜单上方**，每行一条：左边一个标识区分类型（蓝底「待」=待办、橙底「纪」=纪念日），中间是文字，右侧是操作
  - 待办行：文字可点（进编辑框改），右边「**完成**」和「**×**」
  - 纪念日行：**文字也可点**，进编辑框可以改**名称、日期、是否每年重复**；右边「**×**」删除
  - 文字太长不会换行，**单行横向滑动**看全文（下面有一条很细的滑动条）
- 下面只有一个「**＋ 新增**」。点它菜单会切换成一个新增页：

```
新增什么？
[ 待办 ] [ 纪念日 ]     ← 两个按钮，点一下选中（再点一下取消）
[ 先选类型，再写内容  ]   ← 写完回车即保存
```

  - 两个按钮**默认都不选**，不选就回车**不会写入任何东西**，会提示先选类型
  - 选「待办」→ 输入框提示「要做什么」，回车添加待办
  - 选「纪念日」→ 输入框提示「名称，如 生日」，下方多一个「每年重复（只记月日）」勾选项（默认勾上），回车添加纪念日，日期就用你点的那个格子
  - 输入框里按 Esc 可以取消

手机没有右键，用**长按 600ms** 代替。

**我自定义的工作日** — 默认**折叠**，标题右侧显示「上班 N · 休息 N」。**点这一整条横杆**（不只是右边那个按钮）就能展开 / 收起，展开后才露出文本框。可以直接手改：

```
上班: 2026-11-28,2026-11-29
休息: 2026-11-27
```

含「班」的行算上班，含「休 / 假」的行算休息。「上班」优先于国家安排，「休息」优先级最高。

**我的待办 / 我的纪念日**

- 卡片顺序：**我的待办 → 我的纪念日 → 我自定义的工作日**，三张**默认都是收起**的
- 三张卡片都**点整条横杆展开 / 收起**，横杆右侧显示摘要（「未完成 N」「N 个」「上班 N · 休息 N」），收起时也能一眼看到有多少。展开状态会记住，下次打开还是你上次的样子
- 待办：按**逾期 / 今天 / 未来 7 天 / 以后 / 已完成**分组显示，每组标题带条数；每行右侧是相对时间（`逾期 2 天` / `今天` / `明天` / `周三` / `11-27`），鼠标悬停看完整日期。勾选即完成，整行自动挪到「已完成」；「已完成」默认收起，点标题的「展开」才看，不会越堆越长
- 纪念日：`MM-DD` 表示每年重复（生日 / 周年），`YYYY-MM-DD` 表示一次性，列表按「还有几天」排序
- 两张卡片横杆上都有「**＋ 新增**」：待办是「内容 + 日期」，纪念日是「名称 + 日期 + 每年重复」，**写完回车即保存**（Esc 取消，再点一次「＋ 新增」也能收起表单），没有多余的保存/取消按钮
- 也可以在日历格子上右键 / 长按 →「＋ 新增」来添加，那里的日期就是格子的日期

把「我自定义的工作日」文本框清空，即等于清空全部自定义标记。

界面上所有改动（点格子、右键菜单、文本框粘贴、勾选待办）都会**自动保存**，没有保存按钮。

国家放假与调休**由集成自动获取**，界面上没有手工输入年度数据的入口。

如果侧边栏没出现入口，说明面板注册失败（不影响实体），可以改用 Webpage 仪表盘指向 `/my_workday/workday.html`。

> 直接双击本地 `workday.html` 或用预览面板打开时，页面没有登录态，改动不会写入集成（加 `?demo=1` 才会填演示数据）。所有写操作都要从 HA 侧边栏里的页面发起。

## 实体

| 实体 ID | 名称 | 说明 |
|---|---|---|
| `binary_sensor.my_workday_today` | 今天是否工作日 | 上班 `on`，休息 `off` |
| `binary_sensor.my_workday_tomorrow` | 明天是否工作日 | 用于「明晚要不要早睡」 |
| `sensor.my_workday_left` | 本月剩余工作日 | 含今天，单位「天」 |
| `sensor.my_workday_total` | 本月工作日总数 | 单位「天」 |
| `sensor.my_workday_month_progress` | 本月工作日进度 | 百分比，属性带已过 / 总数 / 剩余 |
| `sensor.my_workday_next_holiday` | 距下个节假日 | 天数，属性带假期名与起止日期（会预取次年数据，跨年也能算） |
| `calendar.my_workday` | 工作日日历 | 每个工作日一条全天事件，补班标「补班」、自定义标「上班（自定义）」 |

`calendar.my_workday` 可以直接用 HA 自带的「日历」卡片显示，也能被 `calendar` 触发器使用。

`sensor.my_workday_left` 的附加属性：

| 属性 | 说明 |
|---|---|
| `date` | 计算所依据的日期 |
| `month` | 月份，如 `2026-11` |
| `month_total` | 本月工作日总数 |
| `month_remaining_dates` | 本月剩余工作日的日期列表 |
| `custom_work` / `custom_rest` | 你手动设置的上班日 / 休息日 |
| `holiday_data_year` | 当前使用的放假数据年份 |

## 服务

> 所有服务都支持返回值，自动化里可以 `response_variable` 直接拿结果。例如：
>
> ```yaml
> - action: my_workday.set_day
>   data:
>     date: "2026-11-28"
>     mode: work
>   response_variable: r
> - action: notify.persistent_notification
>   data:
>     message: "改完了，本月还剩 {{ r.month_left }} 个工作日"
> ```

### `my_workday.set_day` — 改某一天

| 字段 | 说明 |
|---|---|
| `date` | 日期，如 `2026-11-28` |
| `mode` | `work` 算上班 / `rest` 算休息 / `auto` 恢复按国家安排 |

```yaml
action: my_workday.set_day
data:
  date: "2026-11-28"
  mode: work
```

### `my_workday.set_custom` — 整批设置

一次替换两份清单，留空即清空该项。

```yaml
action: my_workday.set_custom
data:
  work: "2026-12-28,2026-12-29,2026-12-30"
  rest: "2026-12-25"
```

### `my_workday.clear_custom` — 清空全部自定义日期

```yaml
action: my_workday.clear_custom
```

### `my_workday.refresh_data` — 立即重新拉取今年数据

无参数。会清掉你手动粘贴的同年数据，改为官方数据。

```yaml
action: my_workday.refresh_data
```

### `my_workday.set_year_data` — 手工覆盖整年安排（高级）

界面上**没有**这个入口，正常情况用不到。只在两种情况下手动调：次年安排还没公布但要提前算，或公司内部有独立作息。

| 字段 | 说明 |
|---|---|
| `year` | 年份，不填就是今年 |
| `data` | 安排内容；在 YAML 里设成 `""` 可恢复自动获取 |

每行一组日期 + 一个关键字：含「班」→ 补班；含「休 / 假」或不写 → 按放假处理。支持区间、逗号列表、`#` 注释行，也可以直接粘 holiday-cn 的 JSON。

```yaml
action: my_workday.set_year_data
data:
  year: 2027
  data: |
    2027-01-01~2027-01-03 元旦放假
    2027-02-06 补班
```

### `my_workday.set_anniversaries` — 设置纪念日

| 字段 | 说明 |
|---|---|
| `data` | 每行「名称: 日期」，`生日: 05-20` 表示每年重复、`项目上线: 2026-12-01` 表示一次性；留空即清空 |

### `my_workday.set_todos` — 设置待办

| 字段 | 说明 |
|---|---|
| `data` | 每行「[x] 日期 内容」，`[x]` 表示已完成、可省略；留空即清空 |

```yaml
action: my_workday.set_todos
data:
  data: |
    2026-11-13 交月度报表
    [x] 2026-11-10 提交巡检记录
```

## 提醒（可选）

在 **设置 → 设备与服务 → 我的工作日 → 配置** 里填：

| 字段 | 说明 |
|---|---|
| 通知服务 | 例如 `notify.mobile_app_iphone`，留空则不发提醒 |
| 每天几点提醒 | 默认 `08:00` |
| 假期提前几天提醒 | 逗号分隔，默认 `3,1`（假期前 3 天、前 1 天各提醒一次） |
| 月末剩余工作日 ≤ 几天时提醒 | 默认 `3`，填 `0` 关闭 |

同一步里还能直接编辑「我设的上班日 / 我设的休息日」，不用打开侧边栏界面。

## 排查

**设置 → 设备与服务 → 我的工作日 → 三个点 → 下载诊断信息**，会导出一份 JSON：当前选项、算出来的快照、自定义日期、粘贴过的年份、数据来源。报 bug 时贴这个最快。

## 示例

### 每天 8 点播报本月剩余工作日

```yaml
automation:
  - alias: 本月剩余工作日播报
    triggers:
      - trigger: time
        at: "08:00:00"
    actions:
      - action: notify.persistent_notification
        data:
          title: 本月剩余工作日
          message: >-
            今天{{ '上班' if is_state('binary_sensor.my_workday_today', 'on') else '休息' }}，
            本月还剩 {{ states('sensor.my_workday_left') }} / {{ states('sensor.my_workday_total') }} 个工作日。
```

### 只在工作日开的热水器

```yaml
automation:
  - alias: 工作日早上烧水
    triggers:
      - trigger: time
        at: "06:30:00"
    conditions:
      - condition: state
        entity_id: binary_sensor.my_workday_today
        state: "on"
    actions:
      - action: switch.turn_on
        target:
          entity_id: switch.water_heater
```

### 仪表盘上加两个按钮，一键改今天

```yaml
type: horizontal-stack
cards:
  - type: button
    name: 今天算上班
    icon: mdi:briefcase-check
    tap_action:
      action: perform-action
      perform_action: my_workday.set_day
      data:
        date: "{{ now().strftime('%Y-%m-%d') }}"
        mode: work
  - type: button
    name: 恢复按国家安排
    icon: mdi:backup-restore
    tap_action:
      action: perform-action
      perform_action: my_workday.set_day
      data:
        date: "{{ now().strftime('%Y-%m-%d') }}"
        mode: auto
```

> 旧版本 HA 里 `perform-action` 叫 `call-service`，按你的版本选。

## 数据来源与自动更新

放假数据来自 [NateScarlet/holiday-cn](https://github.com/NateScarlet/holiday-cn)（MIT）。国务院办公厅每年 11—12 月公布次年安排，这个仓库通常在公布后一两天内更新，是目前国内用得最广的一份公开数据源。

**更新时机：**

| 时机 | 行为 |
|---|---|
| HA 启动 | 当年数据不在内存里就拉一次 |
| 每天 0 点 | 重算「今天 / 剩余 / 进度」，跨年自动切换年份 |
| 每周一次 | 复查当年数据，上游年中若有修订会跟上并写日志 |
| 跨年前 | 顺手把次年数据也拉下来（供「距下个节假日」用），失败每 6 小时重试 |
| 手动 | 界面「更新放假数据」按钮，或服务 `my_workday.refresh_data` |

**不需要每年手动改任何东西。** 唯一会卡住的情况是：次年安排还没公布时（一般 12 月中之前），那几天「距下个节假日」会是空的——数据一发布就自动恢复。

如果要换成别的数据源（比如自己维护的 JSON），在**设置 → 设备与服务 → 我的工作日 → 配置**里改地址模板，把 `{year}` 留着即可。默认走 jsDelivr，国内访问不顺时可换成 GitHub Raw。

## 常见问题

**1 月 1 日实体变成"不可用"？**
次年放假安排一般 11—12 月才由国务院公布。如果 holiday-cn 那时还没更新，1 月 1 日起集成会因为拿不到数据而报错——这是故意的，避免给你一个错误的天数。数据一更新就会自动恢复（HA 会定时重试）。

**中午跨零点会不准吗？**
不会。集成每天 0 点 30 秒重算一次，状态直接切换。

**能用在非中国大陆吗？**
不能，判定逻辑写死为中国大陆的法定节假日 + 补班规则。

## 单页切换容器（可选）

`frontend/unified.html` 把「我的工作日」和「我的维护台账」放进同一个页面，顶部一键切换，默认显示日期待办。两个集成都装好后，从 HA 同源打开 `/my_workday/unified.html`；「维护台账」标签上的数字角标是全部到期维护项数。
